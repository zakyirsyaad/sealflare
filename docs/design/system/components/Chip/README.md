A chip is a small square label for a fact about a target or a finding.

## Use

- `sf-chip`: a plain fact in sans, such as the target kind or the chain.
- `sf-chip sf-chip--flag`: a flag name from the contracts, set in mono and written exactly as the contract spells it.
- Add `sf-chip--danger` when the flag was reported as a violation.
- `sf-chip sf-chip--solid-danger`: the filled `blocked` tag in a sandbox log. It is the loudest label in the system, so use it for the sandbox result only.

## Rules

- A chip states a fact that exists. Do not use it for decoration or for marketing words.
- Chips are not buttons. If it can be clicked, it is a Button or a link.
- No rounded ends, no dot, no border.

You provide: the text.
