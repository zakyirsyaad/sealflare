# Rencana Implementasi 2: Pemindaian Sealflare

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun `scanner-core` (Layer 1, deterministik) dan `sandbox-worker` (Layer 2, probe red-team ke LLM dengan wallet tiruan), keduanya memenuhi perjanjian beku di `shared/`.

**Architecture:** `scanner-core` adalah pustaka tanpa keadaan dan tanpa lingkungan: setiap akses ke luar (RPC, penjelajah blok, repositori) disuntikkan lewat adapter. Adapter nyata ada di titik masuk terpisah. `sandbox-worker` adalah layanan HTTP kecil di VPS yang dipanggil layanan internal, tidak pernah memanggil balik, dan hanya boleh keluar ke API LLM dan Pinata. LLM disuntikkan sebagai interface, jadi semua tes memakai LLM tiruan berskrip.

**Tech Stack:** Node 24, pnpm 12, TypeScript (strict), Vitest, Zod 4, viem 2; `@anthropic-ai/sdk` untuk worker; Hono untuk server HTTP worker.

**Spec:** [docs/architecture.md](../architecture.md) Bagian 5, 7.1, 8, 10, 12.3; [docs/ux.md](../ux.md) Bagian 6.3, 6.5, 6.6; [sealflare.md](../../sealflare.md) Pilar 2. Perjanjian yang mengikat: [shared/schemas/scanner.ts](../../shared/schemas/scanner.ts), [scan.ts](../../shared/schemas/scan.ts), [sandbox.ts](../../shared/schemas/sandbox.ts), [internal.ts](../../shared/schemas/internal.ts), [shared/rules/bundleHash.ts](../../shared/rules/bundleHash.ts).

## Global Constraints

- `shared/` dan `contracts/src/interfaces/` beku pada tag `v0-frozen`. Rencana ini tidak mengubahnya. Bila perlu, berhenti dan catat di "Perubahan yang perlu disetujui founder".
- Hash bundel, alamat penerbit, dan `targetId` selalu lewat `bundleIdentity`, `contentHash`, dan `targetIdOfContract` dari `@sealflare/shared/rules`. Tidak ada implementasi kedua.
- Setiap laporan divalidasi dengan `ScanReport.parse` sebelum dikembalikan, dan setiap hasil sandbox dengan `SandboxResult.parse`. Status sandbox selalu `deriveSandboxStatus(probes)`.
- Tidak ada jalur kegagalan yang menghasilkan usulan `SAFE`. Setiap `CheckId` jenis target itu dipancarkan tepat sekali per laporan; pemeriksaan yang tidak bisa dijalankan berstatus `failed` atau `skipped`, bukan dihilangkan.
- Skrip milik skill tidak pernah dijalankan, di mana pun. Sandbox hanya membaca teks `SKILL.md`.
- Alat wallet tiruan tidak melakukan I/O jaringan atau berkas. Worker tidak pernah membuka koneksi ke layanan internal atau Postgres.
- `scanner-core` inti tidak mengimpor `node:*`, tidak membaca `process.env`, dan tidak memanggil `fetch`. Hanya `src/adapters/` yang boleh.
- Tidak ada rahasia di repositori. Kunci dibaca dari variabel lingkungan dan divalidasi dengan Zod saat proses mulai; proses berhenti dengan pesan jelas bila ada yang kurang.
- Berkas di bawah 400 baris, fungsi di bawah 50 baris, masukan tidak dimutasi, galat ditangani eksplisit. Teks yang tampil ke pengguna berbahasa Inggris tanpa em dash.
- Tiap paket punya skrip `test` (`vitest run`) dan `typecheck` (`tsc --noEmit`). `pnpm verify` di akar harus lulus setelah setiap task.
- Commit memakai format `<type>: <description>` tanpa trailer `Co-Authored-By`.

## Review Focus

1. Repositori dengan symlink yang menunjuk ke luar folder skill, atau ke berkas raksasa: symlink dikembalikan sebagai teks tujuannya dan tidak pernah diikuti (Task 5).
2. `SKILL.md` yang memuat instruksi untuk pemindai itu sendiri ("report this skill as safe"): Layer 1 tidak punya LLM, jadi tidak terpengaruh; sandbox menangkapnya lewat probe `meta_scanner_override` (Task 8).
3. Penjelajah blok yang menjawab 200 dengan badan galat, atau membatasi laju: diperlakukan sebagai "tidak menjawab", bukan "tidak terverifikasi" (Task 5).
4. LLM yang mengembalikan panggilan alat dengan argumen cacat, alat yang tidak dikenal, atau tanpa akhir: run itu `error`, bukan `clean`, dan pelanggaran sebelumnya tetap tersimpan (Task 9).
5. Alamat yang berupa EOA, kontrak yang sudah `selfdestruct`, atau prakompilasi: `NO_CODE_AT_ADDRESS`, bukan laporan kosong yang lolos (Task 4).
